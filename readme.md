# 🎂 Birthday Reminder

A simple and beginner-friendly Python command-line application for storing, displaying, searching, and checking birthdays.

---

## 📌 1. Project Overview

The **Birthday Reminder** project is a menu-driven Python application that helps users manage basic birthday information.

The program stores the names and birthdays of people using a Python dictionary. The user can interact with the program through a simple menu displayed in the terminal.

The application provides four main operations:

1. Add a new birthday
2. Display all saved birthdays
3. Search for a particular person's birthday
4. Check whether someone has a birthday on a given date

The program also provides an option to exit the application.

This project is developed using basic Python programming concepts and does not require any external libraries or graphical interface.

---

## 🎯 2. Project Objectives

The main objectives of this project are:

- To develop a simple birthday management application using Python.
- To understand how dictionaries can be used to store related data.
- To practice taking input from the user.
- To understand the use of functions in Python.
- To implement conditional statements.
- To practice using `for` and `while` loops.
- To understand searching in a dictionary.
- To practice counting elements using a variable.
- To use Boolean values for controlling program logic.
- To create a program that can be executed directly from the command line.

---

## 💡 3. Problem Statement

Remembering birthdays of friends, family members, and other people can sometimes be difficult.

The purpose of this project is to create a simple program where birthday information can be stored and accessed easily.

Instead of manually searching through a list, the user can use the program to:

- Add a person's birthday
- View all stored birthdays
- Search for a specific person
- Check birthdays for a particular date

The application provides these operations through a simple menu.
